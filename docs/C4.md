## Sequence — "Paperless für die Familie, nur intern"

```mermaid
sequenceDiagram
  autonumber
  actor A as Admin
  participant S as Solaris (Hand ops)
  participant L as Laib
  participant B as Box-Seite (Authelia)
  participant Q as systemd/Quadlet

  A->>S: "Ich hätte gern Paperless für die Familie, nur intern."
  S->>A: eine Rückfrage (Gruppe family? intern?)
  S->>L: laib_propose --add paperless exposure=internal group=family
  L->>L: Worktree: Template kopieren, laden, rendern
  L-->>S: Vorschlag #17 (Diff)
  L-->>S: Webhook: Vorschlag offen
  S->>A: Card mit Link auf laib.<domain>/inbox
  A->>B: Freigeben (Remote-User, X-Laib-Proxy)
  B->>L: approve #17 als human:admin
  L->>L: merge · Snapshot · render · write
  L->>Q: daemon-reload · restart paperless
  Q-->>L: active · health 200 · Route antwortet
  L->>L: post-deploy Hook (Admin-User anlegen)
  L->>L: Journal: apply grün #c81f2a
  L-->>S: Webhook: Readiness unverändert, Vorschlag entschieden
  S->>A: "Läuft unter paperless.<domain>, SSO ist drauf."
```
